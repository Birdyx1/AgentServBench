# 课程测试用例模板

这是本课程的工程模板，不声称逐条符合 ISO/IEC/IEEE 29119-3。早期练习可以精简填写。

## 用例设计（执行前）

- 用例 ID：
- 用例名称：
- 测试目标／关联业务规则：
- 前置条件与测试数据：用户、订单、工具初始状态、已有业务记录。
- 输入：用户请求；多轮任务注明后续输入。
- 执行步骤：初始化独立环境 → 提交输入 → 执行至结束或超时 → 收集回复、轨迹及业务状态 → 逐项断言。
- 预期结果：最终业务状态、回复要求、允许及禁止的副作用。
- 过程约束：仅记录业务或安全规则要求的硬约束，不预设唯一合法工具路径。
- 判定规则与证据：每项断言注明证据来源；必要证据缺失时标记证据不足，不臆测通过。
- 环境清理：恢复模拟数据与状态，避免用例污染。

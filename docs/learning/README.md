# Agent 评测学习记录

## 学习约定

- 课程方向：ToB 业务侧 Agent 评测，以企业客服 Agent 为贯穿项目。
- 技术主线：原生 Python 最小原理实验 → LangGraph 主项目 → 独立 Evaluation Harness → DeepEval / Ragas；后期增加 Deep Agents 进阶实验。LangChain create_agent 按需快速体验，Pydantic AI 为备选。
- 预算：约 145 小时，预计 10 周；按掌握程度调整，不预设完成日期。
- 每课流程：问题引入 → 原理讲解 → 小示例 → 学员练习 → 导师反馈 → 验收。
- 每阶段维护一份文档，每课结束追加记录；已完成与待验证内容明确分开。
- 练习答案在学员提交后再反馈；每模块安排故障注入与失败分析。
- 仅记录真实发生的学习与运行结果；不把计划、示例或导师演示记为学员已掌握。
- 使用模拟业务数据与模拟退款操作；不在文档中保存 API key、令牌或敏感信息。
- 涉及框架版本和 API 时核对官方文档，并在阶段文档记录版本及来源。
